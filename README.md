One sharp, funny loading-screen tip for stressed developers and AI coding agents, in 200 characters or fewer.

> Tip: your agent rewrote your function in 40 seconds, then spent 20 minutes explaining why the old version was wrong. Trust the diff, not the essay.

## How it works

`main.py` writes the tip — a single line — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Standard library only, no dependencies, no network access.

## Run

```sh
python3 main.py
```

The tip lands in `output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
